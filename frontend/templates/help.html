使用帮助

这是什么

ArmsBank 是一个《灰烬战线》机体数据查询站，本地部署、离线可用。 它把角色、机体、兵装、职能、技能、插件、知性框架、敌人、阿兹班石整理进 PostgreSQL，页面上算出来的面板数值全部来自数据库里的原始值。

数据来源与版本

来源ArmsBank 灰烬战线情报枢纽（arms-bank.com），社区自制情报站
数据版本详见数据库 source 表的 version 字段
记录规模角色 266 · 机体 552 · 技能 6833 · 敌人 5265 · 插件 75 · 框架 109 · 阿兹班石 90 · 弹药 730
用途课程作业，非商业使用；立绘与贴图版权归原权利人所有

面板数值是怎么算的

页面上的面板不是存进数据库的，而是按固定公式实时计算：

生命 / 对地火力 / 对空火力 / 装甲 / 贯通本体 + 兵装 + trunc(兵装 × 职能%)
命中 / 机动 / 幸运 / 暴击概率 / 暴击伤害本体 + 兵装 + 职能定值
反应值只取兵装（本体不参与）

数据库里只存「本体」和「兵装」两份原料，换职能时整张表重算，不写库、也不会出现两份数据打架。

怎么检索

  • 顶部搜索框：跨角色名、角色编号、机体名、机体编号、机体上的专属 / DOLLS / 改造技能名做模糊匹配；多个词用空格分开是「且」的关系。
  • 五个分区：角色、性格插件、知性框架、敌人、阿兹班石各自独立检索，不会互相串。
  • 分组筛选：角色分区顶部可按「学联 / 体型 / 兵种 / 弹药」逐层缩小，条件会写进地址栏，直接分享就是这个视图。
  • 合并展示：狂热 Ⅰ~Ⅴ 在列表里是一张卡，点开后在抽屉顶部切档；敌人同名不同 Lv 也一样。

示例

  1. 搜 KV：能看到 KV-1 / KV-85 等机体，以及命中的技能名。
  2. 进角色详情，点职能标签：13 项面板立即变化，鼠标悬停能看「本体 + 兵装 + 职能」的拆分。
  3. 筛选「重型」+「轰炸机」：列表实时缩到符合条件的角色。
